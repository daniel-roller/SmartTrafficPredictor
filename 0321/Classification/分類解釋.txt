分類器名稱           | 用途簡介                             | 優點                                                 | 缺點
--------------------|--------------------------------------|------------------------------------------------------|-----------------------------------------------------
Decision Tree       | 以「條件判斷」方式進行分類，像問問題 | - 容易理解與解釋                                     | - 容易過擬合
                    |                                      | - 不需標準化資料                                     | - 對異常值敏感
                    |                                      | - 可處理非線性、缺失值                               | - 決策邊界不平滑

Linear SVM          | 找出一條最佳分界直線                 | - 運算快、準確率高                                   | - 只能處理線性可分的資料
                    |                                      | - 解釋性強                                           | - 對噪聲敏感

Polynomial SVM      | 利用高次多項式轉換來分類資料         | - 可處理非線性資料                                   | - 計算較慢
                    |                                      | - 表現彈性比 Linear 好                               | - 高次多項式易過擬合、需調參

Random Forest       | 多棵決策樹投票，提升穩定與準確率     | - 精準度高                                           | - 模型較大、訓練時間較久
                    |                                      | - 抗過擬合、穩定性佳                                 | - 難以清楚解釋每棵樹的邏輯
                    |                                      | - 可看特徵重要性                                     |


情境                                | 建議使用分類器
-----------------------------------|-------------------------
需要可解釋的分類邏輯               | Decision Tree
資料明顯線性可分                   | Linear SVM
資料非線性但不太複雜               | Polynomial SVM（建議低次）
希望準確率高且抗噪聲能力強         | Random Forest


模型名稱         | 指定方法                                | 關鍵參數範例
----------------|-----------------------------------------|--------------------------
Decision Tree   | DecisionTreeClassifier()                | max_depth, criterion 等
Linear SVM      | SVC(kernel='linear')                    | 無需額外參數
Polynomial SVM  | SVC(kernel='poly', degree=3)            | degree（多項式次數）
Random Forest   | RandomForestClassifier(n_estimators=100)| n_estimators（樹數）
