確保你的檔案結構如下：

```

├── data_loader.py
├── data_processor.py
├── traditional_models.py
```

### ▶️ 步驟 3：執行主程式

## 🔧 常見調整

### 想要更多或更少樣本？

編輯 `config.py`：

```python
MAX_SAMPLE_SIZE = 10000  # 改成你想要的數量，例如 5000 或 20000
```

### 想要調整訓練/測試比例？

編輯 `config.py`：

```python
TRAIN_RATIO = 0.7   # 訓練集 70%
VAL_RATIO = 0.15    # 驗證集 15%
TEST_RATIO = 0.15   # 測試集 15%
```

### 想要修改模型參數？

編輯 `config.py` 中的 `TRADITIONAL_ML_PARAMS`：

```python
'RandomForest': {
    'n_estimators': 100,    # 樹的數量，增加可能提升準確度但會更慢
    'max_depth': 10,        # 樹的深度
    'random_state': 42
}
```

## ❓ 遇到問題？

### 問題 1：找不到 CSV 檔案
```
❌ 在 select/ 中找不到 CSV 檔案
```

**解決方法：** 確認 CSV 檔案在 `1014/select/` 資料夾中

### 問題 2：記憶體不足
```
MemoryError: Unable to allocate array
```

**解決方法：** 減少 `config.py` 中的 `MAX_SAMPLE_SIZE`

### 問題 3：模組找不到
```
ModuleNotFoundError: No module named 'xxx'
```

**解決方法：** 重新執行安裝指令
```bash
pip install numpy pandas scikit-learn xgboost matplotlib seaborn
```
