# 📋 專案檔案結構說明

根據您的需求「我想要全部從頭做起」，以下是專案的檔案分工和說明：

## 🗂️ 核心檔案組織

### 1️⃣ **config.py** - 系統配置中心
**功能：** 集中管理所有系統參數
- 路徑設定（資料夾位置）
- 模型參數（3 個基本模型的設定）
- 訓練參數（分割比例、樣本數量等）
- 特徵工程參數

**為什麼需要：** 方便統一調整參數，避免在多個檔案中重複修改

---

### 2️⃣ **data_loader.py** - CSV 數據載入器
**功能：** 從 select/ 資料夾載入 CSV 檔案
- 讀取 4 個交通流量 CSV 檔案
- 將資料轉換為時間序列格式（滑動窗口）
- 提取 Flow 和 Speed 特徵
- 限制樣本數量避免記憶體不足

**為什麼需要：** CSV 格式不能直接用於模型訓練，需要轉換成 (X, y) 格式

**範例流程：**
```
CSV (381382 行) → 時間窗口切分 → 限制到 10000 樣本 → (X, y) 數據
```

---

### 3️⃣ **data_processor.py** - 數據預處理與特徵工程
**功能：** 增強數據特徵，提升模型性能
- 基本統計特徵（平均、標準差、最大、最小等）
- 滯後特徵（過去 1, 2, 3 個時間點的數據）
- 數據分割（訓練集 70%、驗證集 15%、測試集 15%）
- 標準化處理（讓不同尺度的特徵在同一範圍）

**為什麼需要：** 原始特徵可能不足以捕捉交通模式，需要工程化處理

**處理流程：**
```
原始 24 維 → 基本特徵 6 維 + 滯後特徵 3 維 → 總共 33 維特徵
```

---

### 4️⃣ **traditional_models.py** - 機器學習模型訓練器
**功能：** 訓練 3 種傳統模型
- **Ridge Regression**：線性模型，速度快
- **Random Forest**：隨機森林，準確度高
- **XGBoost**：梯度提升，平衡性能與速度

**為什麼需要：** 不同模型有不同特性，比較後選擇最適合的

**訓練過程：**
```
載入數據 → 訓練模型 → 驗證集評估 → 測試集評估 → 交叉驗證 → 儲存模型
```

---

### 5️⃣ **evaluator.py** - 模型評估與視覺化
**功能：** 比較所有模型的性能
- 計算評估指標（R², RMSE, MAE, MAPE）
- 生成視覺化圖表（一頁式儀表板）
- 產生摘要報告（Markdown 格式）
- 匯出 CSV 結果

**為什麼需要：** 讓結果一目了然，方便做決策

**輸出檔案：**
- 整體模型比較儀表板.png
- 模型比較摘要報告.md
- 模型比較結果.csv

---

### 6️⃣ **utils.py** - 工具函數庫
**功能：** 提供共用的輔助函數
- 數據驗證
- 計時器
- 進度條
- 檔案儲存/載入
- 格式化輸出

**為什麼需要：** 避免重複寫相同的程式碼

---

### 7️⃣ **main.py** - 主程式入口（一鍵執行）
**功能：** 整合所有模組，執行完整流程
1. 設定實驗環境
2. 載入 CSV 數據
3. 數據預處理
4. 訓練模型
5. 評估結果
6. 生成報告

**為什麼需要：** 簡化操作，只需執行 `python main.py` 即可完成所有步驟

---

## 📊 資料流程圖

```
CSV 檔案 (select/)
    ↓
[data_loader.py] 讀取與轉換
    ↓
原始時間序列數據 (X, y)
    ↓
[data_processor.py] 特徵工程
    ↓
增強特徵 + 訓練/驗證/測試集分割
    ↓
[traditional_models.py] 訓練 3 個模型
    ↓
訓練好的模型 + 預測結果
    ↓
[evaluator.py] 評估與視覺化
    ↓
報告 + 圖表 (results/)
```

---

## 🎯 為什麼要分這些檔案？

### ✅ **模組化設計的優點：**

1. **責任分離**：每個檔案只負責一件事，容易理解和維護
2. **可重複使用**：需要單獨載入數據？直接用 data_loader.py
3. **容易測試**：可以單獨測試每個模組
4. **方便協作**：多人可以同時編輯不同檔案
5. **易於擴充**：要加新模型？只需修改 traditional_models.py

### ❌ **如果全部寫在一個檔案：**
- 程式碼很長（超過 1000 行），難以閱讀
- 修改一處可能影響其他地方
- 無法重複使用程式碼
- 難以找到特定功能

## 🚀 使用建議

### 完全從頭開始：
```bash
# 1. 準備數據：將 CSV 放入 select/ 資料夾
# 2. 執行主程式
python main.py
```

### 只想測試數據載入：
```bash
python data_loader.py
```

### 想要調整參數：
```python
# 修改 config.py 中的參數
MAX_SAMPLE_SIZE = 10000  # 改成你想要的樣本數
```

---

## 📝 修改順序建議

如果您想分次詢問或修改，建議順序：

1. **先看 config.py** - 了解系統參數
2. **再看 data_loader.py** - 理解數據如何載入
3. **接著 data_processor.py** - 學習特徵工程
4. **然後 traditional_models.py** - 掌握模型訓練
5. **最後 evaluator.py** - 了解結果評估

**main.py 和 utils.py** 只需要在整合時關注。
