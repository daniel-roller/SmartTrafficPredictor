## 🔄 執行流程

```
1. 啟動系統
   └─> python main.py

2. 載入數據
   └─> data_loader.py 讀取 4 個 CSV

3. 資料預處理
   ├─> 時間序列轉換（滑動窗口）
   ├─> 特徵工程（統計 + 滯後）
   └─> 分割數據（訓練/驗證/測試）

4. 模型訓練（每個測站）
   ├─> Ridge Regression
   ├─> Random Forest
   └─> XGBoost

5. 評估與輸出
   ├─> 計算評估指標
   ├─> 生成視覺化圖表
   ├─> 產生摘要報告
   └─> 匯出 CSV 結果

6. 完成
   └─> 查看 results/ 資料夾
```
