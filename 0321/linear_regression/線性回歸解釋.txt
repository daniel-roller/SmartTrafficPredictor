模型名稱             | 原理簡介                         | 優點                                             | 缺點
--------------------|----------------------------------|--------------------------------------------------|---------------------------------------------------
Linear Regression    | 傳統線性回歸模型，找出最適直線    | - 簡單易懂                                       | - 容易過擬合
                     |                                  | - 訓練速度快                                     | - 對異常值敏感
                     |                                  | - 無正則化，適合理想條件                         | - 當特徵很多或共線性強時表現不佳

Ridge Regression     | 線性回歸 + L2 正則化             | - 可抑制模型複雜度，降低過擬合                   | - 所有特徵仍會被保留（不做特徵選擇）
（L2 正則化）        |                                  | - 適合特徵多、有共線性的問題                     | - 仍可能受離群點影響

Lasso Regression     | 線性回歸 + L1 正則化             | - 可「自動挑選特徵」，將不重要特徵係數變 0       | - 過度懲罰可能會錯殺有用特徵
（L1 正則化）        |                                  | - 有助於建立簡潔模型（特徵選擇）                 | - 當特徵數 > 筆數時效果不佳

模型名稱             | 呼叫方式                         | 重要參數說明
--------------------|----------------------------------|-------------------------------
Linear Regression    | LinearRegression()               | 無需額外參數
Ridge Regression     | Ridge(alpha=1.0)                 | alpha 越大 → 模型越簡單，抗過擬合越強
Lasso Regression     | Lasso(alpha=0.1)                 | alpha 越大 → 越多特徵會被「壓成 0」

分析需求情境                         | 建議使用模型
------------------------------------|-----------------------------
資料乾淨、變數不多                  | Linear Regression
特徵多、有些互相關聯               | Ridge Regression
想進行特徵選擇（自動篩掉不重要變數）| Lasso Regression
