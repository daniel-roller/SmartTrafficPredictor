# 💡 模型與參數調整總覽

---

## 🎯 Decision Tree
| 參數               | 功能說明                                                        |
|--------------------|------------------------------------------------------------------|
| `max_depth`        | 限制樹的深度，避免過擬合。越大 → 越複雜。                        |
| `min_samples_split`| 控制節點是否繼續分裂的樣本數，越大 → 模型越簡單。                |
| `criterion`        | 分裂依據（如 Gini、Entropy），決定如何分割資料。                   |

---

## 🌲 Random Forest
| 參數           | 功能說明                                                        |
|----------------|------------------------------------------------------------------|
| `n_estimators` | 樹的數量。越多 → 模型穩定但訓練時間增加。                         |
| `max_depth`    | 每棵樹最大深度。越大 → 越複雜，可能過擬合。                       |
| `max_features` | 每次分裂考慮的特徵數，控制隨機性與泛化能力。                      |

---

## 🧭 SVM
| 參數     | 功能說明                                                              |
|----------|------------------------------------------------------------------------|
| `C`      | 懲罰係數。越大 → 模型更偏向完全分類訓練資料（可能過擬合）。              |
| `kernel` | 核函數（如 linear、rbf），決定轉換空間與分類方式。                      |
| `gamma`  | 決定每筆資料的影響範圍。大 → 過度擬合；小 → 平滑但可能欠擬合。            |

---

## 📈 Logistic Regression
| 參數        | 功能說明                                      |
|-------------|------------------------------------------------|
| `C`         | 正則化強度。越小 → 越強的懲罰（避免過擬合）。 |
| `max_iter`  | 最大迭代次數，避免模型提早停止訓練。           |

---

## 👥 KNN
| 參數          | 功能說明                                                            |
|---------------|----------------------------------------------------------------------|
| `n_neighbors` | 鄰居數量（K 值），越大 → 穩定但模糊，越小 → 敏感但不穩定。           |
| `weights`     | 距離加權方式（uniform 或 distance），決定鄰居影響力。                |
| `metric`      | 距離計算方法（如 euclidean、manhattan），影響相似度判斷。             |

---

## ⚡ XGBoost
| 參數            | 功能說明                                                           |
|------------------|---------------------------------------------------------------------|
| `n_estimators`   | 樹的數量，越多 → 越穩定但越慢。                                    |
| `max_depth`      | 每棵樹的深度，越大 → 越複雜。                                        |
| `learning_rate`  | 學習率，越小 → 越穩但需要更多樹，越大 → 快但風險震盪。              |

---

## 🐱 CatBoost
| 參數           | 功能說明                                                           |
|----------------|---------------------------------------------------------------------|
| `iterations`   | 樹的數量，功能同 `n_estimators`。                                   |
| `depth`        | 樹的深度，越深越容易擬合。                                           |
| `learning_rate`| 學習率，與 XGBoost 相同。                                            |

---

## 🧪 特徵選擇 / 資料處理
| 名稱           | 功能說明                                                           |
|----------------|---------------------------------------------------------------------|
| `SelectKBest(k)`| 保留前 K 個特徵，降維提高泛化能力。                               |
| `SMOTE`         | 合成新樣本平衡類別。參數如 `k_neighbors` 會影響樣本多樣性。       |
