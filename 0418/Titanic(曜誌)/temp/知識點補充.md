# 1. kaggle和seaborn差別

| 項目            | Seaborn                                     | Kaggle                                                       |
|-----------------|---------------------------------------------|---------------------------------------------------------------|
| 使用難度        | ⭐ 很簡單，適合初學者                         | ⭐⭐⭐ 中高，需處理原始資料與缺失值                            |
| 安裝方式        | `pip install seaborn` 即可                   | 須註冊帳號、登入下載資料，或設定 API                        |
| 資料載入方式    | `sns.load_dataset("titanic")`               | `pd.read_csv("train.csv")` 讀取本地 CSV                      |
| 資料集格式      | 已處理過的 Pandas DataFrame                 | 原始資料，常有缺值與雜訊                                     |
| 資料內容        | 適合教學與練習，欄位較乾淨                   | 真實世界數據（含姓名、艙位、文字欄位等）                    |
| 缺失值          | 較少，處理好                                 | 需要手動處理（如年齡、登船港缺失）                           |
| 適合任務        | 模型練習與圖表展示（快速上手）               | 完整專題與實戰任務（資料清理 + 模型 + 預測）                |
| 規模與彈性      | 小型，固定欄位                               | 資料量較多，可做分類、回歸、分群、自訂任務                  |
| 其他說明        | 不需下載資料，可立即練習                     | 是競賽資料，可做 leaderboard 提交，也常見於專題或報告使用  |
